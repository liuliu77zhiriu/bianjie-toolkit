# 便捷工具 · 用户手册

## 1. 启动与常驻

双击 `便捷工具.exe` 后：

- 桌面边缘出现一个半透明蓝色悬浮球（默认在屏幕右侧中部）；
- 点击悬浮球 → 打开主面板；再次点击或按 `Esc` / 右上角 × 关闭；
- 悬浮球可拖动到任意位置，靠近屏幕边缘会自动吸附；鼠标移开 2 秒后自动变淡，靠近即恢复。
- **贴边半隐藏**：把悬浮球拖到屏幕左/右边缘，它只露出一小条（带一条蓝色亮边作为把手）；鼠标靠近边缘时自动平滑弹出，鼠标移开后约 0.7 秒重新藏回边缘。可在 设置 → 外观 → 贴边半隐藏 中关闭。
- 关闭窗口不会退出应用，它常驻系统托盘（任务栏右下角蓝色小图标）。托盘菜单可以打开面板、截图、录制、切换悬浮球、进入设置或退出。

> 如果悬浮球被隐藏：托盘菜单 → 显示悬浮球；或按 `Alt + Space` 打开面板后在设置里恢复。

## 2. 主面板

- 顶部：当前页面标题、返回、设置、关闭；拖动顶部空白区域可以移动面板。点齿轮会打开**独立设置窗口**（不是面板内页面）。
- 首页：快捷操作（区域截图 / 全屏截图 / 录制屏幕）+ 全部工具卡片 + 扩展入口。
- 底部 Dock：首页 / 截图 / 备忘录 / 计时器 / 设置，一键切换。
- 首页底部左侧：**UI 编辑器**入口（可视化设计工作台，见第 9 节）；中间是**流光搜索**入口（见第 10 节）；右侧是扩展工具箱入口。
- 面板为系统级毛玻璃（Win11 acrylic），可在外观设置里调节不透明度和动画强度。

## 3. 截图

打开「截图」工具：

- **区域截图**：点击后主面板自动收起，屏幕变暗；按住鼠标拖出矩形，松开即完成；`Esc` 或右键取消。结果自动复制到剪贴板并保存到「图片/便捷工具截图」。
- **全屏截图**：选择显示器后一键截取整个屏幕。
- **指定窗口截图**：在来源面板切换「窗口 / 屏幕」，点击缩略图即可截取（即使窗口被部分遮挡也可以）。
- 截图完成后回到面板可查看最近一次截图、尺寸与路径，支持「打开文件夹 / 复制」。

保存格式、自动复制、完成后是否回到面板，可在 设置 → 截图 中调整。快捷键：`Alt + A` / `Alt + S`。

## 4. 录屏

打开「录制」工具：

1. 选择来源（屏幕或某个窗口），可刷新缩略图；
2. 选择音频：系统声音（录制电脑播放的声音）/ 麦克风 / 两者 / 静音；
3. 设置帧率、画质、倒计时；
4. 点击「开始录制」后主面板收起，桌面右上角出现红色「录制中」小窗，显示时长，可随时点停止；再次按 `Alt + R` 也可开始/停止；
5. 结束后文件保存到「视频/便捷工具录制」，面板中可打开文件或文件夹。

默认 MP4（H.264 + AAC），系统不支持时自动回退 WebM。

## 5. 备忘录

- 顶部搜索框支持按标题/内容搜索；
- 点「新建」进入编辑，输入标题和正文后自动保存（约 0.4 秒防抖），也可 `Ctrl + S` 立即保存；
- 列表按置顶优先、更新时间倒序排列；支持置顶、删除（二次确认）、查看更新时间与字数；
- 数据保存在本机 `%APPDATA%\便捷工具\plugin-data\memo.json`。

## 6. 计时器

- **秒表**：开始 / 暂停 / 计次 / 重置，记录每圈时间；
- **倒计时**：选择 1/3/5/10/25/45 分钟预设，或自定义分秒；开始后显示环形进度，结束时系统通知 + 迷你窗闪烁提示；
- 开始计时后，桌面右上角会自动出现**迷你计时窗**：显示时间，可暂停/继续、重置、关闭（关闭只隐藏窗口，计时继续）；
- 关闭主面板后计时照常进行；应用重启时，正在运行的计时会安全暂停并保留已计时长；
- 快捷键：`Alt + T` 开始/暂停（如启用），托盘「快捷操作」也可控制。

## 7. 设置（独立窗口）

点击面板右上角齿轮、底部 Dock 的「设置」，或托盘菜单 →「设置」，会单独弹出一个可缩放的**设置窗口**（侧边栏 + 宽内容区，`Esc` 关闭，可最小化）。它和小面板互不挤占，设置窗口打开时面板可以继续使用。

- **通用**：开机自启、显示悬浮球、失焦自动收起、记住面板尺寸、恢复默认设置。
- **外观**：强调色（5 套预设 + 自定义色值）、面板不透明度、毛玻璃开关、动画强度（完整/轻量/关闭）、悬浮球尺寸与透明度、自动隐藏、贴边吸附、**贴边半隐藏**、窗口置顶、底部 Dock 显示。
- **个性化**：主题、壁纸、自定义设计（见下一节）。
- **快捷键**：点击输入框后按下组合键即可录制；保存后显示是否注册成功及冲突；支持一键恢复默认。
- **截图**：保存目录、PNG/JPG、自动复制、完成后回到面板、提示音。
- **录制**：保存目录、帧率、画质、音频来源、倒计时、格式、最长录制时长。
- **扩展**：启用/禁用插件、重新加载、打开目录、恢复默认、删除用户插件；新建插件、导入插件；点「编辑代码」进入代码编辑器。
- **关于**：版本与运行时信息、打开数据/日志/截图/录制目录、导出/导入设置、重启、退出。

## 8. 个性化（壁纸 / UI 主题）

设置窗口 →「个性化」：

- **UI 主题**：内置 6 套（午夜蓝黑 / 深海 / 极光 / 石墨 / 暮色 / 极简黑），点击卡片即时应用强调色、毛玻璃、透明度、动效、悬浮球与壁纸组合；当前主题带「使用中」标记。
- **壁纸**：
  - 内置 6 张 1920×1080 暗色壁纸，点击缩略图即可应用；
  - 「导入本地图片」支持 PNG/JPG/WebP，复制到数据目录，不修改原文件；
  - 「下载壁纸」粘贴图片 URL 即可下载并应用（仅 image、≤30MB、20 秒超时）；
  - 可调「壁纸可见度」，让图片只作为黑玻璃后的隐约底纹；
  - 「设为 Windows 桌面壁纸」会把当前壁纸设置成系统桌面（会真实修改桌面，需要确认）；
  - 我的壁纸可删除，删除当前壁纸会自动清空应用内选择。
- **设计器**：自己调强调色、面板不透明度、毛玻璃、动画强度、悬浮球尺寸/透明度/贴边半隐藏、Dock 显示；调好后输入名字「保存为我的主题」，之后可在主题区一键切换，最多保存 30 套。
- 壁纸和主题设置会同时作用到主面板与设置窗口，即时生效、无需重启。

## 9. UI 编辑器

首页底部左侧「UI 编辑器」卡片打开独立工作台（托盘菜单也可打开）。详见 [UI 编辑器文档](UI_EDITOR.md)，快速上手：

- **画布**：滚轮平移、`Ctrl+滚轮` 缩放；空格/中键拖拽；单击选择、Shift 多选、框选；拖拽移动、8 向手柄缩放、旋转；移动时网格/边缘/中心吸附并显示参考线；方向键微调；`Ctrl+0` 适配；
- **创建**：工具栏选择容器/矩形/圆形/线段/文本/图片后拖拽绘制；按钮、输入框、开关、滑杆、Tabs 等点击即插入；双击文本直接改字；
- **组件/模板**：左面板「组件」29 个内置组件；「模板」7 套完整页面（登录、仪表盘、设置、媒体、移动端、看板、空白）；
- **图层**：左面板拖拽调整前后/父子层级、重命名、显隐、锁定；「页面」管理多页面、尺寸与背景；
- **右面板**：属性（几何/布局/填充/描边/圆角/阴影/文字/类型专属）、设计（颜色/间距/圆角/文字令牌）、交互（点击/悬停/加载 → 页面/链接/返回/切换/命令 + hover/pressed 状态样式）；
- **预览**：顶栏「预览」全屏运行，支持页面跳转与交互；`Esc` 退出；
- **保存/导出**：自动保存 + `Ctrl+S`；顶栏「导出」可导出**独立 HTML / 工程 JSON / React 组件**，或**发布为应用内工具**；
- **工程库**：顶栏文件夹按钮 / 文件 → 最近工程，可打开、复制、删除、导入工程；工程保存在 `%APPDATA%\便捷工具\uieditor\projects\`。

## 10. 流光搜索（搜索引擎 / 下载器）

首页底部中间的「流光搜索」卡片，打开独立白色玻璃窗口（可用 `Ctrl+K` 聚焦顶部快速搜索）。详见 [流光搜索文档](SEARCH.md)：

- **搜索**：输入后 `Enter`，支持 Bing / DuckDuckGo（设置切换）；结果含图标、标题、域名、摘要，可打开/复制/收藏/加入下载；支持搜索建议、分页、历史记录；
- **下载器**：粘贴 http/https 文件直链或从搜索结果加入；队列显示进度、速度、大小；支持暂停/继续（断点续传）、取消、重试、打开文件/文件夹、删除记录；并发 1–6 可调；
- **历史/书签/设置**：历史按日期分组、可清空；书签打开/删除；设置搜索引擎、结果数、并发、动画、历史开关、保存目录；
- **流体背景**：白色基底上的珠光流体，鼠标移动/点击有交互；可在设置关闭动画效果（关闭后静态）；
- 数据目录：`%APPDATA%\便捷工具\search\`（搜索设置/历史/书签/下载记录）。

## 11. 自定义工具（代码编辑）

所有工具都是插件。设置 → 扩展 → 选择插件 → **编辑代码**：

- 左侧是插件文件树（`plugin.json`、`main.js`、`index.html`、`app.js`、`style.css`、`icon.svg` 等），右侧是带语法高亮的编辑器；
- **新建文件**：工具栏「新建文件」→ 输入相对路径（如 `lib/helpers.js`，支持子目录）→ 选模板（空白/JS/HTML/CSS/JSON/Markdown），创建后可立即编辑；
- **删除文件**：文件树每项 hover 出现删除按钮。删除自己的覆盖文件会露出内置原版；删除内置文件会写入「墓碑」隐藏，并在下方「已删除文件」区块中随时**恢复**（重启后仍保留）；
- **全屏编辑**：工具栏全屏按钮（或再次点击）让编辑器占满窗口，`Esc` 只退出全屏；文件列表与编辑器之间的分隔线可拖拽调宽；
- 修改后点「保存并应用」（或 `Ctrl + S`）：语法校验 → 自动备份 → 写入覆盖层并**热重载**，无需重启；出错时保留编辑并显示错误，可「恢复默认」；
- 你的修改保存在 `%APPDATA%\便捷工具\overrides\<插件id>\`，不会破坏内置文件；删除的内置文件记录在同目录 `.deleted.json`；
- 「扩展 → 新建插件」会生成一个可运行的最小模板，适合从零写自己的小工具。插件 API 见 `docs/PLUGIN_SDK.md`。

## 12. 数据与卸载

- 数据目录：`%APPDATA%\便捷工具`（设置、插件覆盖层、备忘录、计时器状态、日志、`wallpapers\` 用户壁纸、`themes.json` 自定义主题）；
- 截图：`图片\便捷工具截图`；录屏：`视频\便捷工具录制`（可在设置中修改）；
- 卸载：直接删除程序目录；如需彻底清理，删除数据目录与上述图片/视频目录即可（绿色软件，不写注册表，除开机自启外）。

## 13. 常见问题

| 问题 | 处理 |
| --- | --- |
| 快捷键没反应 | 可能被其它软件占用：设置 → 快捷键 查看状态并更换；`Alt+Space` 也会与部分输入法冲突。 |
| 截图/录屏黑屏或没有画面 | 关闭显卡驱动覆盖层（如游戏加加、录屏软件叠加层）；确认没有开启 HDR 独占；必要时在设置里关闭毛玻璃后重试。 |
| 托盘图标不见了 | Windows 托盘折叠区里找蓝色图标；或在任务管理器结束进程后重新启动。 |
| 插件界面白屏/报错 | 设置 → 扩展 → 重新加载；仍失败则可「恢复默认」或打开目录查看错误。 |
| 想恢复出厂设置 | 设置 → 通用 → 恢复默认设置；或删除 `%APPDATA%\便捷工具\settings.json` 后重启。 |
| 壁纸下载失败 | 仅支持直接指向图片的 URL（image/*，≤30MB，20 秒超时）；图床防盗链/需要登录的链接会失败，可先下载到本地再用「导入本地图片」。 |
| 误删了内置插件文件 | 设置 → 扩展 → 编辑 → 下方「已删除文件」→ 恢复；若已点「恢复默认」则覆盖层整体重置，需重新编辑。 |
| 设置窗口没反应/不见了 | 从托盘菜单 →「设置」重新打开；窗口关闭只是隐藏，重新打开会保留上次分类。 |
| 流光搜索没有结果/报错 | Bing/DuckDuckGo 外部服务可能被网络限制或反爬，设置里切换引擎，或点「在浏览器搜索」；下载失败检查链接是否直链/防盗链。 |
| UI 编辑器界面显示不全/卡顿 | 先关闭其他占用 GPU 的程序；画布使用缩放渲染，超大工程可拆分多页面；窗口最大化后性能更好。 |
| 导出的 HTML 打不开/图片丢失 | 本地图片会内嵌为 DataURL；外链图片需要联网；若用 file:// 打开被浏览器限制，可放到本地服务器或直接双击（本应用导出为单文件）。 |
| 发布的 UI 工具没出现 | 关闭并重新打开主面板查看；设置 → 扩展 中确认插件已启用；发布时会自动重新加载插件。 |
